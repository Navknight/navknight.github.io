Reverse Linked List ★

recursive: reverse the rest, head->next->next = head, head->next = null

Difficulty
Easy
Complexity
O(n) time, O(n) space

Problem

Reverse a linked list.

Approach

Recursion

Reverse the rest to get newHead. Point head->next->next back at head, cut head->next to avoid a cycle.

Code

ListNode* reverseList(ListNode* head) {
    if(!head || !head->next)
        return head;
    ListNode* newHead = reverseList(head->next);
    head->next->next = head;
    head->next = nullptr;
    return newHead;
}

Complexity

  • Time: O(n)
  • Space: O(n)
